# ⌨️ PixelType (tap.dii)

A premium, retro-themed typing test application built with React and Vite. Experience the nostalgia of CRT terminals while mastering your typing speed and accuracy.

## 🚀 Features
- **Retro Aesthetic**: CRT scanline effects, pixel fonts, and a sleek dark theme.
- **Dynamic Scrolling**: Smooth 2-line word carousel that advances as you type.
- **Bilingual Support**: Toggle between English and Vietnamese word lists.
- **Accurate Metrics**: Real-time WPM (Words Per Minute) and Accuracy tracking.
- **Audio Feedback**: Satisfying mechanical keyboard sounds.
- **Performance Charts**: Visualize your typing speed throughout the test.

## 🛠️ Tech Stack
- **Framework**: React 19
- **Bundler**: Vite
- **Styling**: Vanilla CSS (Custom properties, CRT filters)
- **Charts**: Recharts
- **Icons**: Custom Pixel SVGs

## 📦 Installation
1. Clone the repository
2. Install dependencies: `npm install`
3. Start development server: `npm run dev`

## 🌐 Deployment
This project is optimized for deployment on Cloudflare Pages, Vercel, or Netlify.
